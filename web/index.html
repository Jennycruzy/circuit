About this page

Every row is read from Studio Next with readContract on the three contracts in config.json. Nothing is simulated: proposals are real transactions, verdicts are the stored output of a real validator committee, and a veto is a real message from the Circuit contract to the governor. Decoded actions are decoded in the browser from the proposal's raw calldata with the same codec the contracts use; Circuit's own on-chain decode is shown in the detail view when an assessment exists.
